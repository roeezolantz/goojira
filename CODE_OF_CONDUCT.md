# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, focus on the work. Disagree about code, not about people.

## Reporting

Concerns about behavior in this project — issues, PRs, discussions, or any other project space — should be reported privately to the maintainer at **zolantz.roee@gmail.com**.

Reports are handled confidentially. The maintainer will acknowledge within a few days and respond with what action (if any) will be taken.

## Scope

This applies anywhere the project's name is used: the GitHub repo, releases, and any community spaces that may be added later.
